# Grocery Hub Backend

This folder contains the Express.js API for the Grocery Hub inventory and billing system.

## Scripts

- `npm install`
- `npm run dev`

## API Overview

- `POST /api/auth/login`
- `GET /api/products`
- `POST /api/products`
- `PUT /api/products/:id`
- `GET /api/sales`
- `POST /api/sales`
- `GET /api/reports/dashboard`
- `GET /api/reports/sales`
